# FlowRoute

Android-клиент для VLESS с распределением подключений между серверами и резервным каналом QWDTT.

## Возможности

- группы серверов из отдельных конфигов, подписок и QR-кодов;
- распределение трафика по очереди, случайно, по задержке или нагрузке;
- закрепление приложений за серверами;
- отдельные правила маршрутизации и список приложений для VLESS и QWDTT;
- пресеты для ресурсов РФ, заблокированных ресурсов и белых списков;
- автоматический переход на QWDTT при недоступности VLESS;
- статистика трафика, задержек и доступности серверов;
- журнал ошибок и проверка внешних IP;
- обновления через GitHub Releases;
- экспорт и импорт конфигурации.

## Установка

Нужен Android 8.0 или новее на устройстве ARM64.

Скачайте APK со страницы [релизов](https://github.com/Sanchesko330/FlowRoute/releases). Android попросит разрешить установку из выбранного источника.

Приложение проверяет новые релизы при запуске, но не чаще одного раза в 12 часов. Проверку также можно запустить кнопкой «Проверить обновления» на главной.

## Переход с debug на release

Debug и release подписаны разными ключами, поэтому release нельзя установить поверх debug. Сначала сохраните конфигурацию через «Экспорт», удалите debug-версию, установите release и выберите «Импорт».

Резервная копия содержит адреса серверов, подписки и пароли QWDTT в открытом виде. Не отправляйте файл посторонним.

Подробнее: [docs/RELEASE.md](docs/RELEASE.md).

## Сборка

Требуются JDK 21 и Android SDK 35.

```bat
gradlew.bat testDebugUnitTest lintDebug assembleDebug
gradlew.bat assembleRelease
```

Для release нужен собственный keystore. Его параметры читаются из `..\FlowRoute-signing\keystore.properties` или переменных окружения. Ключи, пароли и локальные файлы не входят в репозиторий.

## Исходный код

- `app/src/main/java/dev/flowroute/app` — интерфейс и логика Android;
- `app/src/main/java/dev/flowroute/app/core` — VPN, Xray и QWDTT;
- `app/src/main/java/dev/flowroute/app/data` — конфигурация, подписки и резервные копии;
- `qwdtt` — клиентская и серверная части QWDTT;
- `app/src/test` — модульные тесты.

Перед отправкой изменений запустите:

```bat
gradlew.bat testDebugUnitTest lintDebug
```
