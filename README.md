# FlowRoute

FlowRoute — Android-клиент для VLESS с распределением трафика между серверами и резервным подключением QWDTT.

## Возможности

- объединение серверов в группы;
- добавление отдельных конфигов, подписок и QR-кодов;
- распределение подключений по очереди, случайно, по задержке или нагрузке;
- закрепление приложений за одним сервером;
- автоматическое переключение на QWDTT при недоступности VLESS;
- отдельные правила маршрутизации для VLESS и QWDTT;
- выбор приложений, которые используют VPN;
- готовые пресеты для ресурсов РФ, заблокированных ресурсов и белых списков;
- статистика скорости, трафика, задержки и доступности серверов;
- журнал ошибок и проверка внешних IP;
- резервное копирование настроек;
- обновления через GitHub Releases.

## Установка

Приложение работает на Android 8.0 и новее на устройствах ARM64.

1. Скачайте APK со [страницы релизов](https://github.com/Sanchesko330/FlowRoute/releases).
2. Откройте файл и разрешите установку из выбранного источника.
3. Создайте группу и добавьте в неё конфиги или подписку.
4. Выберите группу на главной и нажмите «Подключить».

При первом подключении Android покажет системный запрос разрешения VPN.

## Маршрутизация

В разделе «Правила» можно выбрать, какие ресурсы открываются через VPN, напрямую или блокируются. Для VLESS и QWDTT настройки раздельные.

В разделе «Приложения» задаётся список приложений для выбранного канала. Доступны поиск и готовые списки приложений РФ, заблокированных приложений и приложений из белого списка.

## Резервная копия

На главной доступны экспорт и импорт конфигурации. В копию входят группы, серверы, подписки, правила и настройки приложения.

Файл содержит адреса серверов, ссылки подписок и пароли QWDTT в открытом виде. Храните его в защищённом месте и не передавайте посторонним.

## Обновления

Приложение проверяет новые версии при запуске, но не чаще одного раза в 12 часов. Проверку также можно запустить вручную кнопкой «Проверить обновления» на главной.

После скачивания Android покажет системное окно установки. Группы и настройки сохраняются при обычном обновлении.
